# 🌐 FalkorDB Knowledge Graph Explorer & Agent

An interactive Knowledge Graph application and AI Agent powered by **FalkorDB**, **LangChain**, and **Streamlit**. Built for graph-based context retrieval, visual relationship modeling, and dynamic data ingestion.

## 🚀 Features

- **Knowledge Graph Database**: Low-latency graph operations using FalkorDB (via Docker).
- **Interactive Graph Visualization**: Dynamic node-edge connection rendering built with Streamlit & `streamlit-agraph`.
- **Dynamic Context Ingestion**: Easily add new entities, projects, and relationships directly to the live graph.
- **Cypher Query Interface**: Execute custom Cypher graph traversal queries directly from the UI.
- **LangChain / OpenAI Agent Ready**: Script interface to query graph data using LLM tool calling.

## ⚙️ Tech Stack

- **Database**: FalkorDB (Docker Container)
- **Frontend / UI**: Streamlit, streamlit-agraph
- **Backend / Agent Framework**: Python, LangChain, OpenAI API
- **Graph Query Language**: Cypher
